# Definition of Ready (DoR)

A user story may enter a sprint only when all of the following are true:

- [ ] It is written as "As a …, I want …, so that …". A spike has a clear question it answers.
- [ ] It has acceptance criteria that can be verified.
- [ ] It is estimated in story points and is **not larger than 8 SP**.
- [ ] It has a priority and belongs to an epic.
- [ ] It is broken down into subtasks, each with an estimate in hours and a layer
  (UI / logic / database / tests / docs).
- [ ] Its dependencies are resolved, or are in the same sprint and scheduled before it.
- [ ] The team understands it and there are no open questions.
