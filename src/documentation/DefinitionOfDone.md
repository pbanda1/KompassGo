# Definition of Done (DoD)

> Applies to **every user story**. A story is **Done** only when **all 7 criteria** are met.
> A spike is done when its question is answered and documented in Jira or Confluence.

| # | Criterion | What it means |
|---|-----------|---------------|
| 1 | **Works on every team member's computer** | A fresh `git clone` of `main`, set up only by following the README, starts the app and the main scenario works. |
| 2 | **Acceptance criteria met** | All acceptance criteria of the story are met. |
| 3 | **Build and tests are green** | `.\mvnw.cmd verify` (macOS/Linux: `./mvnw verify`) passes locally and in CI: **BUILD SUCCESS**, all tests pass. |
| 4 | **Reviewed through a pull request** | Work is done on a `feature/SCRUM-xx-...` branch, every commit message starts with the Jira key, and the PR is approved by **at least 1** other member before merging into `main`. |
| 5 | **Clean repository** | No passwords, secrets or absolute paths. Code, comments and database objects are in English. |
| 6 | **Database through scripts only** | Changes are only in `initDB.sql` / `seedDB.sql` / `resetDB.sql`. The database generates all IDs. No manual steps in the database. |
| 7 | **Documentation and Jira updated** | README / documentation is updated, and the story and all its subtasks are in **Done** in Jira. |

## Checklist (copy into the pull request)

- [ ] Works on every team member's computer
- [ ] All acceptance criteria are met
- [ ] `mvnw verify` is green locally and in CI
- [ ] Feature branch, Jira key in commits, PR approved by 1+ member
- [ ] No secrets or absolute paths, everything in English
- [ ] Database changes only in SQL scripts, IDs generated by the database
- [ ] Documentation updated, story and subtasks in Done
